1. 応用コード一覧について

応用コード一覧は、Webサイト制作で再利用できるHTML・CSS・JavaScriptのサンプルをまとめた機能です。掲載コードは完成済みのWebサイト一式ではなく、特定の機能を実装するための部品・例です。プロジェクトの構造に合わせて調整して利用してください。

この機能の検索はブラウザー内で行います。検索のためにAIへ入力内容を送信する仕組みは使用しません。

2. 検索の使い方

  1. 検索欄に機能名、用途、関連する単語を入力します。
  2. 名前の一部だけでも検索できます。例：「メニュー」「画像」「ログイン」「コピー」。
  3. 意味が近い別の言葉やタグも検索対象です。例：「写真」で画像関連、「スマホ」でレスポンシブ関連を探せます。
  4. 分類ボタンを使うと、関連する機能だけに絞り込めます。
  5. 検索結果の「使い方・説明・注意点」を開き、コードを使う前に必要なHTML要素や設定を確認します。

3. 分類一覧

  • ナビゲーション：メニュー、ヘッダー、ページ移動、上部へ戻る機能。
  • デザイン・レイアウト：カード配置、配色、背景、レスポンシブ表示。
  • フォーム・入力：入力検証、文字数表示、パスワード表示切り替え。
  • アカウント：ログイン、セッション、プロフィールのサンプル。
  • 画像・メディア：画像プレビュー、拡大表示、スライダー。
  • 操作・表示：モーダル、タブ、通知、読み込み中表示。
  • 検索・データ：一覧検索、お気に入り、ページ分割。

4. コードをプロジェクトに組み込む手順

  1. 先にプロジェクトを保存し、元に戻せる状態にします。
  2. コードの説明を読み、必要なHTML要素・ID・クラスを確認します。
  3. HTMLコードはページ構造、CSSコードはスタイル、JavaScriptコードは動作を担当する場所へ追加します。
  4. 同じIDが複数存在しないか、コード内のID・クラス名がHTML側と一致しているか確認します。
  5. プレビューでPC・スマートフォンの両方を確認し、コンソールのエラーも確認します。
  6. 問題がなければ保存し、公開前にもう一度動作確認します。
コードをそのまま貼り付けても、既存コードとの競合や不足しているHTML要素によって動作しない場合があります。

5. セキュリティ・プライバシー上の注意

  • APIキー、パスワード、秘密鍵、Supabaseのservice_roleキーなどをHTML・CSS・JavaScriptへ直接記載しないでください。
  • ログイン状態を画面上で確認するだけでは、データへのアクセス制限になりません。データベース側のアクセス制御も必要です。
  • フォームの入力値はブラウザーだけでなく、サーバー側でも検証してください。
  • 利用者が入力した文字列をHTMLとして無検証で挿入しないでください。表示時は適切にエスケープしてください。
  • 画像やファイルのアップロードを追加する場合は、形式・容量・アクセス権限を別途検証してください。

6. 互換性・アクセシビリティ・性能

  • 利用するブラウザーで対応しているAPIやCSS機能か確認してください。
  • ボタンには用途が分かる名前を付け、キーボード操作とフォーカス表示を確保してください。
  • 画像には内容を説明する代替テキストを設定してください。
  • アニメーションは動きを減らす設定への配慮を行い、過剰な演出を避けてください。
  • スマートフォンやタブレットでも表示崩れ、横スクロール、押しにくいボタンがないか確認してください。

7. 掲載コードの利用範囲と免責

掲載コードは学習・制作の参考例です。利用する人は、自分のプロジェクトに合わせて内容を確認・調整してください。コードの導入によって発生したデータ消失、表示不具合、外部サービスの停止などを防ぐため、導入前のバックアップとテストを推奨します。外部サービスを利用する場合は、そのサービスの利用規約・公式仕様も確認してください。
