MULTI-PAGE WEBSITE

複数ページのWebサイトを作る

Webサイトは1ページだけでも、複数ページに分けても作れます。内容の量と目的に合わせて構成しましょう。

01 / ページを追加

ページ一覧から追加

制作エディターの「＋ ページを追加」を押します。新しいページが作られたら、ページ一覧から選んでタイトル・文章・HTMLを編集します。

index.html / page-2.html
02 / ページを分ける

内容ごとに整理

トップページには概要、別ページには詳細・作品一覧・料金・お問い合わせなどを配置すると、情報を探しやすくなります。

トップ / About / Contact
03 / ページをつなぐ

リンクで移動

ページ間の移動にはaタグを使います。ファイル名を正しく指定すると、クリックして別ページへ移動できます。

<a href="page-2.html">詳細</a>
ページ数を決める目安

簡単な案内やプロフィールなら1ページ、サービス紹介なら2〜4ページ、ブログ・ショップ・大規模サイトなら用途に応じてページを増やします。ページ数を増やすこと自体を目的にせず、1ページに情報を詰め込みすぎないことが大切です。

ACCOUNT PAGE

アカウントページの作り方

プロフィールを見せるページと、実際にログイン・登録できる仕組みは別です。順番に作りましょう。

STEP 01 · ページの土台

必要な項目を整理する

プロフィール画像・表示名・メールアドレス・設定・ログアウトなどをカード単位に分けます。アカウントページのテンプレートから始めることもできます。

アカウントページのテンプレートを見る →
STEP 02 · 認証機能

新規登録・ログインを接続する

Supabase Authなどの認証サービスを使います。ログイン後はセッションからユーザー情報を取得し、画面に反映します。

client.auth.getSession()

コード一覧：認証・プロフィール →

STEP 03 · プロフィール編集

入力内容を保存する

表示名やプロフィール画像を編集できるようにします。画像はStorageなどにアップロードし、公開範囲を適切に設定します。

client.auth.updateUser({ data: { display_name } })
STEP 04 · データ保護

ユーザーごとに閲覧権限を分ける

DBのRLSを有効にし、本人の行だけ読み書きできるポリシーを設定します。画面でボタンを隠すだけではアクセス制御になりません。

service_roleキーや秘密鍵をHTML・JavaScriptに書かないでください。公開用キーを使い、権限はDB側で制限します。

NAVIGATION SYSTEM

三本線メニュー・ナビゲーションの作り方

メニューは見た目だけでなく、開閉・移動・キーボード操作・スマホ対応まで設計します。

STEP 01 · HTML

ボタンとリンクを用意

開閉ボタンにはaria-expanded、ナビにはaria-labelを付けます。リンク先は実在するページ名にします。

<button id="menu-toggle" aria-expanded="false" aria-controls="site-menu">☰ メニュー</button>
<nav id="site-menu" hidden aria-label="メインメニュー">
  <a href="index.html">ホーム</a>
  <a href="account.html">アカウント</a>
</nav>
STEP 02 · CSS

画面端に固定する

position:fixed、z-index、max-height、overflow-y:autoを組み合わせ、画面が小さくてもメニュー内をスクロールできるようにします。

.site-menu{position:fixed;inset:0 0 0 auto;width:min(86vw,360px);max-height:100dvh;overflow-y:auto;z-index:100}
.menu-backdrop{position:fixed;inset:0;z-index:99;background:#0009}
STEP 03 · JavaScript

開閉・閉じる動作を実装

ボタン・背景・リンク・Escキーのどれからでも閉じられるようにします。開いている間の背景スクロールも必要に応じて止めます。

コード一覧：三本線メニュー →

STEP 04 · よく使うメニュー機能

項目を整理する

details/summaryの折り畳み、現在ページの強調表示、ログイン状態による項目切り替え、未読数バッジ、管理者専用項目などを追加できます。
